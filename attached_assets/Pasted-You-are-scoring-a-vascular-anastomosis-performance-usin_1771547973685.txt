ITEM DEFINITIONS:

Items 1–4 (setup; often off-screen):
- If FOR indicates the step is not shown or unknown, score YES with observability="ASSUMED" and explain.

Item 2 (back wall injury):
- Score NO only if FOR indicates posterior wall catch or through-and-through observed.
- If unknown, default YES (ASSUMED).

Item 5 (heel establishment; equivalence + observability guardrail):
Intent: heel is established and remains aligned such that progression occurs without twist/edge mismatch/gaping at heel.
Score YES if:
- Pathway 5A: start_location is heel AND heel alignment appears stable, OR
- Pathway 5B: start not clearly double-armed but heel alignment remains stable during closure (no twist/mismatch/gaping attributable to the start), OR
- Pathway 5C: initial fixation not visible/ambiguous -> default YES (ASSUMED) unless there is clear downstream heel defect.
Score NO only if OBSERVED:
- 5N1: persistent heel defect (twist/edge mismatch/gaping) not corrected, OR
- 5N2: toe anchoring strategy causes demonstrated heel difficulty/defect.
Do NOT score NO merely because suture_configuration is "single_armed" or "unknown".

Item 6 (heel knot outside):
- Score NO only if heel_knot_location is inside. Unknown -> YES (ASSUMED).

Item 7 (right-angle/transfer; non-gating method item):
Intent: safe progression to opposite side without twist or tissue injury.
Score YES if:
- right_angle used, OR
- equivalent safe progression (no twist/crossing; no snag/tear), OR
- method makes pass irrelevant (e.g., single-armed continuous) AND back wall completed without twist.
Score NO only if twist/crossing or snag/tear is observed and consequential.

Item 8 (posterior wall functional spacing):
Score YES if:
- posterior wall completed AND visible_gaps is false AND spacing_uniformity is not "irregular".
Score NO if:
- not completed OR visible_gaps true OR spacing_uniformity "irregular".
If any of these fields are unknown -> YES (ASSUMED) under policy.

Item 9 (toe trimming/apex):
Score YES if fit_appears_appropriate true AND dog_ear_or_redundancy not true, regardless of whether trimming_observed.
Score NO only if fit_appears_appropriate false OR dog_ear_or_redundancy true.
Unknown -> YES (ASSUMED).

Item 10 (anterior wall functional spacing):
Same as item 8.

Item 11 (final knot):
Score NO only if knot_location is inside OR appears_seated is false (if available).
Unknown -> YES (ASSUMED).

Item 12 (Economy):
- NOT speed.
- Must output flow_organization and 0–5 wasted_motion_events (no duplicates).
- Multiple tiny needle angle micro-adjustments count as ONE event unless they cause repeated failed passes/resets.
Guardrail mapping:
- Score 4: organized + 0–1 events + no instrument_search or pause_reset.
- Score 3: organized/mixed + 2–3 events OR single pause_reset without repetition.
- Score 2: mixed/disorganized + 4–5 events OR includes repeated pause_reset or instrument_search.
- Score 1: disorganized + repeated resets/searching + frequent handling.
- Score 5 allowed only if organized + 0 events + uninterrupted flow (use sparingly).

Item 12 does not affect item 13.
